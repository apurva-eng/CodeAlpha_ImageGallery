# CodeAlpha Image Gallery

## Project Overview

A responsive image gallery web application built using HTML, CSS and JavaScript.

## Features

- Responsive image grid
- Image categories filter
- Lightbox preview
- Next and previous navigation
- Smooth hover animations
- Mobile friendly design

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How To Run

1. Download project
2. Open index.html
3. View in browser
